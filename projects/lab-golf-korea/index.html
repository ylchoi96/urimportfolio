UI/UX Case Study · L.A.B. GOLF KOREA

Bringing L.A.B. GOLF
to the Korean market.

미국에서 운영되던 L.A.B. GOLF가 한국 공식 판매를 시작하면서, 국내 고객을 위한 별도 커머스 경험이 필요했습니다. 브랜드 이해, 제품 탐색, 커스텀 옵션 선택, 피팅 예약까지 하나의 흐름으로 연결한 프로젝트입니다.

RoleUI/UX Design · Publishing · Front-end
PlatformCafe24
ScopeCommerce · Custom Options · Fitting
MarketSouth Korea
01 · Overview

Why this project started.

L.A.B. GOLF는 미국 기반의 퍼터 브랜드로, 한국에서 공식 유통 계약을 통해 판매를 시작하게 되면서 국내 고객을 위한 별도 온라인 쇼핑몰 구축이 필요했습니다.

기존 미국몰의 브랜드와 제품 정보를 그대로 복제하는 대신, 한국 고객이 익숙하게 탐색하고 구매할 수 있도록 콘텐츠 구조와 사용자 흐름을 다시 정리했습니다. 제품 판매뿐 아니라 브랜드 소개, 커스텀 퍼터 옵션, 오프라인 피팅 예약까지 실제 운영에 필요한 경험을 하나의 사이트 안에 통합했습니다.

02 · Challenges

What needed to be solved.

이 프로젝트의 핵심은 화면을 새로 만드는 것보다, 해외 브랜드의 복잡한 제품 구조를 한국형 커머스 맥락 안에서 이해하기 쉽게 재구성하는 것이었습니다.

01

Localization

미국 브랜드의 톤과 제품 정보를 유지하면서도 한국 사용자가 자연스럽게 이해할 수 있는 정보 순서와 표현이 필요했습니다.

02

Product complexity

퍼터 모델, 샤프트, 길이, 헤드 무게 등 옵션이 많아 단순한 상품 상세 구조만으로는 선택 과정이 복잡하게 느껴질 수 있었습니다.

03

Online ↔ Offline

온라인 상품 탐색과 오프라인 피팅 예약을 분리하지 않고 하나의 서비스 경험으로 이어지게 해야 했습니다.

04

Live commerce constraints

Cafe24 환경 안에서 디자인 의도를 유지하면서도 실제 운영과 유지보수가 가능한 구조로 구현해야 했습니다.

03 · Solution

A guided commerce experience.

사용자가 브랜드를 이해하고, 제품을 비교하고, 옵션을 선택하고, 필요하면 피팅까지 이어질 수 있도록 핵심 경험을 네 영역으로 나눠 설계했습니다.

01 · Product Discovery

Desktop for comparison.
Mobile for focus.

PC에서는 여러 제품을 한 번에 비교할 수 있도록 정보 밀도를 높였고, 모바일에서는 핵심 정보와 CTA에 집중하도록 구조를 단순화했습니다.

02 · Custom Configuration

From complex options
to a guided flow.

커스텀 퍼터 옵션을 한 번에 노출하지 않고 Foundation → Function → Form의 3단계로 나눠 사용자가 현재 위치와 다음 행동을 쉽게 이해할 수 있도록 설계했습니다.

Foundation Function Form Review
03 · Fitting Journey

A service journey,
not just a reservation page.

예약 버튼만 제공하는 것이 아니라, 서비스 안내 → 매장 정보 → 혜택 → 예약까지 사용자가 충분히 이해한 뒤 행동할 수 있도록 콘텐츠 흐름을 구성했습니다.

04 · AI-assisted Visual Production

Creating visual assets
when source imagery was missing.

일부 컬러 에디션과 프로모션 영역은 브랜드에서 제공된 이미지가 충분하지 않았습니다. 필요한 비주얼은 AI-assisted image creation을 활용해 제작하고, 최종 사이트에 적용 가능한 형태로 리터칭·구성했습니다.

AI는 대체 디자인이 아니라 제작 보조 도구로 사용했습니다. 페이지 목적과 브랜드 톤을 먼저 정의한 뒤 이미지 생성 → 선택 → 보정 → 실제 UI 적용 순으로 진행했습니다.

04 · Results

What the project delivered.

수치 성과를 임의로 만들기보다, 실제 프로젝트에서 구현된 구조와 역할을 기준으로 결과를 정리했습니다.

01
Localized commerce structure

미국 브랜드의 정보 구조를 한국 고객의 구매 흐름에 맞게 재구성했습니다.

02
Clearer custom option flow

복잡한 제품 옵션을 단계형 UX로 정리해 선택 과정을 이해하기 쉽게 만들었습니다.

03
Connected fitting experience

온라인 탐색과 오프라인 예약을 하나의 서비스 여정으로 연결했습니다.

04
Design to implementation

UI/UX 설계뿐 아니라 Responsive Publishing, Cafe24 적용, 실제 운영 환경까지 직접 연결했습니다.
