UI/UX Case Study · L.A.B. GOLF KOREA

Bringing L.A.B. GOLF
to the Korean market.

미국에서 운영되던 L.A.B. GOLF가 한국 공식 유통 계약을 통해 판매를 시작하면서, 국내 고객을 위한 별도 온라인 커머스 플랫폼 구축이 필요했습니다. 이 프로젝트는 브랜드 소개, 제품 탐색, 커스텀 옵션 선택, 피팅 예약까지 하나의 사용자 여정으로 연결하는 것을 목표로 진행했습니다.

RoleUI/UX Design · Responsive Publishing · Front-end
PlatformCafe24
ScopeCommerce · Custom Configuration · Fitting Service
MarketSouth Korea
Homepage · Responsive Experience Desktop + Mobile · Localized commerce launch
01 · Overview

Why the Korean site needed to exist.

L.A.B. GOLF는 미국 기반 퍼터 브랜드입니다. 한국에서 공식 판매를 시작하면서 국내 고객이 브랜드와 제품을 이해하고 구매할 수 있는 별도의 온라인 채널이 필요했습니다.

기존 미국몰을 그대로 복제하는 대신, 한국 고객의 탐색 방식과 실제 판매 환경에 맞춰 정보 구조를 다시 정리했습니다. 제품 판매뿐 아니라 커스텀 퍼터 옵션, 피팅 서비스, 매장 예약 콘텐츠까지 한 사이트 안에서 연결되도록 설계하고 Cafe24 환경에 직접 구현했습니다.

02 · Challenges

Turning a specialized product into a clear digital journey.

화면을 새로 만드는 것보다 더 중요한 과제는, 전문 제품의 복잡성을 줄이고 한국 고객이 이해할 수 있는 구매 흐름으로 바꾸는 것이었습니다.

01

Localization

미국 브랜드의 제품 정보와 톤을 유지하면서 한국 고객에게 자연스러운 정보 순서와 표현으로 재구성.

02

Product complexity

모델, 샤프트, 길이, 헤드 무게 등 다수의 옵션을 구매 단계에서 쉽게 이해할 수 있도록 구조화.

03

Online ↔ Offline fitting

상품 탐색에서 오프라인 피팅 예약까지 맥락이 끊기지 않는 서비스 여정 설계.

04

Cafe24 implementation

디자인 의도를 유지하면서 실제 운영·수정·상품 관리가 가능한 Cafe24 구조로 퍼블리싱.

Brand→Discover→Compare→Configure→Fitting→Purchase / Visit
03 · Solution

Four design decisions shaped the experience.

핵심 기능을 단순히 나열하지 않고, 실제 사용자의 판단 순서에 맞춰 Product Discovery → Configuration → Fitting → Visual Communication의 흐름으로 정리했습니다.

01 · Product Discovery

Desktop for comparison.
Mobile for focus.

PC에서는 여러 모델을 한눈에 비교할 수 있도록 정보 밀도를 유지하고, 모바일에서는 핵심 정보와 행동 요소를 중심으로 화면을 단순화했습니다.

Product Listing · Responsive System Desktop comparison / Mobile focus
Design decision

같은 콘텐츠를 단순 축소하지 않고, PC에서는 여러 제품을 비교하기 쉬운 밀도를 유지하고 모바일에서는 카테고리와 상품 카드에 집중하도록 정보 우선순위를 다시 설계했습니다.

Product Detail · DesktopProduct media · price · option hierarchy · purchase CTA
02 · Custom Configuration

From complex options
to a guided flow.

커스텀 퍼터는 옵션을 한 번에 보여주기보다 단계형 구조가 필요했습니다. Foundation → Function → Form으로 분리하고 현재 단계, 선택 상태, 최종 금액을 지속적으로 확인할 수 있게 구성했습니다.

03 · Fitting Journey

A service journey,
not just a reservation form.

피팅 예약은 단순한 전환 버튼이 아니라 브랜드 신뢰를 만드는 과정으로 보았습니다. 서비스 안내, 전문 피터, 혜택, 매장 정보, 예약 진입점을 하나의 흐름으로 연결했습니다.

04 · AI-assisted Visual Production

Creating missing brand visuals
for live commerce content.

일부 프로모션과 컬러 에디션은 제공된 제작 이미지가 충분하지 않았습니다. 페이지 목적과 브랜드 톤을 먼저 정의한 뒤 AI-assisted image creation을 활용해 필요한 키비주얼을 제작하고 실제 UI에 적용했습니다.

AI는 디자인을 대체하는 용도가 아니라 제작 보조 도구로 사용했습니다. 비주얼 방향 설정 → 이미지 생성 → 선택 및 보정 → 실제 랜딩 UI 적용의 순서로 진행했습니다.
04 · Results

What the project delivered.

임의의 성과 수치를 만들지 않고, 실제 구축 범위와 개선된 경험을 기준으로 정리했습니다.

01
Localized commerce structure

미국 브랜드의 제품·콘텐츠 구조를 한국 고객의 구매 흐름에 맞게 재구성.

02
Guided custom configuration

복잡한 커스텀 옵션을 단계형 선택 과정으로 정리해 현재 상태와 다음 행동을 명확하게 전달.

03
Connected fitting experience

온라인 정보 탐색과 오프라인 피팅 예약을 하나의 서비스 여정으로 연결.

04
Design → live implementation

UI/UX 설계에서 끝나지 않고 Responsive Publishing, Cafe24 적용, 실제 운영 구조까지 직접 연결.
